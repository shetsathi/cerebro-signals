### 1. LocalFileRepository

**File:** `src/historical/local-file-repository.ts`

**Status:** ✅ COMPLETE AND READY

**Contract:**
```typescript
class LocalFileRepository {
  constructor(datasetRootDir: string = 'datasets')
  
  async saveDataset(
    manifest: DatasetManifest,
    candles: Candle[]
  ): Promise<{ manifestPath: string; candlesPath: string }>
  
  async loadDataset(datasetId: string): Promise<LocalDataset | null>
  
  async streamCandles(filePath: string): AsyncGenerator<Candle>
  
  async loadAllCandles(filePath: string): Promise<Candle[]>
  
  listDatasets(): string[]
  
  async deleteDataset(datasetId: string): Promise<void>
}
```

**Key Implementation Details:**

1. **Directory Structure:**
   - Root: `datasets/` (created automatically if missing)
   - Per-dataset: `datasets/{datasetId}/manifest.json`
   - Per-dataset: `datasets/{datasetId}/candles.jsonl`

2. **Candle Serialization Format (JSONL):**
   - One JSON object per line (newline-delimited JSON)
   - Each line is a complete candle serialized as:
     ```json
     {
       "symbol": "NIFTY 50",
       "timeframe": "FIVE_MINUTE",
       "openTimeUTC": "2023-08-21T03:45:00.000Z",
       "closeTimeUTC": "2023-08-21T03:50:00.000Z",
       "ohlc": {
         "open": 19250.5,
         "high": 19265.25,
         "low": 19240.0,
         "close": 19255.75,
         "volume": 1250000
       },
       "status": "CLOSED",
       "knowledgeTimeUTC": "2023-08-21T03:50:00.000Z"
     }
     ```

3. **Manifest Serialization Format (JSON):**
   - Single JSON file with metadata about the dataset
   - Contains: datasetId, source, instrument, timeframe, dateRange, candleCount, timezone, schema, validation, checksumSHA256, importedAtUTC, normalizationVersion

4. **Deserialization:**
   - Reads JSONL line-by-line, parses JSON, reconstructs domain `Candle` objects
   - Returns candles in chronological order (already sorted by `openTimeUTC`)
   - Generator pattern for streaming (memory-efficient for large datasets)

5. **Determinism Guarantee:**
   - Candles are sorted by `openTimeUTC` during save
   - Load returns candles in same sorted order
   - Multiple loads produce identical results

**Assessment:** ✅ **READY FOR USE**
- No bugs observed
- No modifications needed
- Method signatures are stable
- Directory creation is automatic

interface DatasetManifest {

  };
  checksumSHA256: string;         // SHA256 of raw source data

  normalizationVersion: string;   // e.g., "1.0"
}

### 12. Angel One Historical Fetcher Integration

**File:** `src/adapters/angel-one-historical-fetcher.ts`

**Status:** ✅ READY

**Returns:** `AngelOneCandle[]` with format:
```typescript
{
  date: string;        // "DD-MMM-YYYY HH:MM" (IST) from SmartAPI
  open: number;
  high: number;
  low: number;
  close: number;
  volume: number;
}
```

**Required Conversion:**
```typescript
// 1. Fetch from Angel One
const fetcher = new AngelOneHistoricalFetcher();
const rawCandles: AngelOneCandle[] = await fetcher.fetchHistoricalData(
  '5m', 
  '2023-08-21 09:15', 
  '2026-08-21 15:30'
);

// 2. Convert to domain Candle[] via data-contracts
const config: HistoricalImportConfig = {
  source: 'angel-one',
  timezone: 'Asia/Kolkata',
  assumeKnowledgeTime: 'closeTime',
  strictValidation: false,
  allowGaps: true
};

const convertedCandles: Candle[] = [];
for (const raw of rawCandles) {
  const { candle, errors } = rawToCandleModel(
    {
      symbol: 'NIFTY 50',
      timeframe: 'FIVE_MINUTE',
      openTime: raw.date,
      closeTime: raw.date,  // Will compute from openTime
      open: raw.open,
      high: raw.high,
      low: raw.low,
      close: raw.close,
      volume: raw.volume,
      timezone: 'Asia/Kolkata'
    },
    config
  );
  if (candle) convertedCandles.push(candle);
}

// 3. Validate
const validator = new HistoricalDataValidator();
const validation = validator.validateBatch(convertedCandles);

// 4. Create manifest
const manifest = ManifestBuilder.generate(
  'NIFTY-5m-2023-2026',
  'angel-one',
  'NIFTY 50',
  'FIVE_MINUTE',
  convertedCandles,
  'Asia/Kolkata',
  validation.errors,
  validation.warnings,
  ManifestBuilder.checksumData(JSON.stringify(rawCandles)),
  '1.0'
);

// 5. Persist
const repo = new LocalFileRepository('datasets');
const { manifestPath, candlesPath } = await repo.saveDataset(
  manifest,
  convertedCandles
);
```

**Assessment:** ✅ **CLEAN INTEGRATION**
- No modifications needed to fetcher
- Conversion pipeline is straightforward
- All components work together without friction
