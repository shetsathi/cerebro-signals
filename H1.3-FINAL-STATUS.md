Once executed with valid credentials, the dataset will be at:

```

├── manifest.json        (metadata + checksum)
└── candles.jsonl        (one Candle per line, chronologically sorted)
```

**Format:**
- `manifest.json`: JSON with datasetId, source, symbol, timeframe, candleCount, checksumSHA256, etc.
- `candles.jsonl`: Newline-delimited JSON. Each line is a serialized Candle:
  ```json

  ```
