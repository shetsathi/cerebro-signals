## PERSISTENCE WORKFLOW

### Data Flow

```
Angel One SmartAPI
    ↓ fetchHistoricalData()
AngelOneCandle[] { date, open, high, low, close, volume }
    ↓ convertAngelOneCandlesToDomain()
Candle[] (domain model, UTC timestamps)
    ↓ HistoricalDataValidator.validateBatch()
✓ Validation report
    ↓ ManifestBuilder.generate()
DatasetManifest (with SHA256 checksum)
    ↓ LocalFileRepository.saveDataset()
datasets/NIFTY-5m-2023-2026/
  ├── manifest.json
  └── candles.jsonl
    ↓ LocalFileRepository.loadDataset() [verification]
✓ Persistence verified
```

### Step 13 Detailed Flow

1. **Conversion** (convertAngelOneCandlesToDomain)
   - For each Angel One candle with timestamp T (IST):
     - Parse T using parseTimestampUTC() → UTC date
     - Compute closeTimeUTC = T (in UTC)
     - Compute openTimeUTC = T - 5 minutes (in UTC)
     - Pass to rawToCandleModel() with HistoricalImportConfig
     - Collect converted Candle or error

2. **Sorting**
   - Sort domain Candle[] by openTimeUTC ascending
   - Deterministic ordering guaranteed

3. **Validation** (HistoricalDataValidator)
   - Check for duplicates (by candle ID)
   - Check for out-of-order (by openTimeUTC)
   - Check for missing intervals (gap analysis)
   - Check session boundaries (IST 09:15-15:30)
   - Report errors and warnings (continue on warnings)

4. **Manifest Creation** (ManifestBuilder)
   - Compute SHA256 of raw Angel One data
   - Extract first/last timestamps from sorted Candle[]
   - Generate manifest with:
     - datasetId: "NIFTY-5m-2023-2026"
     - source: "angel-one"
     - instrument: "NIFTY 50"
     - timeframe: "FIVE_MINUTE"
     - candleCount: actual count
     - timezone: "Asia/Kolkata"
     - validation status and errors
     - checksumSHA256
     - importedAtUTC (current time)

5. **Persistence** (LocalFileRepository.saveDataset)
   - Create directory: `datasets/NIFTY-5m-2023-2026/`
   - Write manifest to: `datasets/NIFTY-5m-2023-2026/manifest.json`
   - Write candles to: `datasets/NIFTY-5m-2023-2026/candles.jsonl`
   - Each line in candles.jsonl is a JSON-serialized Candle
   - Files are deterministically ordered by openTimeUTC

6. **Independent Verification**
   - Reload dataset via `LocalFileRepository.loadDataset()`
   - Load all candles via `LocalFileRepository.loadAllCandles()`
   - Verify:
     - loadedCandleCount == persistedCandleCount
     - first candle timestamp matches
     - last candle timestamp matches
     - manifest.json exists and > 0 bytes
     - candles.jsonl exists and > 0 bytes
   - Report file sizes and manifest checksum
